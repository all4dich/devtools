# K8S Cluster Management

## AWS Node Management
* aws/aws-k8s-master.sh
  * Start k8s master node and connect to it by ssh
* aws/aws-k8s-worker.sh
    * Start k8s worker node and connect to it by ssh
* aws/aws-k8s-startall.sh
  * start master/worker nodes
* aws/aws-k8s-statusall.sh
  * Get all EC2 node's status
* aws/aws-k8s-stopall.sh
  * Stop all EC2 nodes for the cluster
* aws/aws-k8s-startall-us-west.sh
  * Start master/worker nodes on us-west-1
* aws/aws-k8s-statusall-us-west.sh
    * Get all EC2 node's status on us-west-1
* aws/aws-k8s-stopall-us-west.sh 
    * Stop all EC2 nodes for the cluster on us-west-1
